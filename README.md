# SafeVisit AI — Landing page

Landing page conceptual para una startup de tecnología sanitaria que propone apoyar la validación visual de EPP de visitantes en áreas de aislamiento hospitalario.

## Archivos
- `index.html`: estructura y contenido de la landing page.
- `styles.css`: diseño responsive, modo oscuro, acentos cian, panel de producto y animaciones.
- `script.js`: menú móvil, navbar sticky y aparición progresiva de elementos.
- `images/hero_visual.png`: tablero visual de marca generado con IA, incluido como recurso conceptual.

## Cómo abrir
1. Descomprime la carpeta.
2. Abre `index.html` en un navegador moderno.
3. Para publicarla, sube la carpeta completa a tu proveedor de hosting estático.

## Personalización antes de publicar
- Sustituye `contacto@safevisit.ai` por el correo real en `index.html`.
- Confirma el nombre comercial, textos legales, política de privacidad y canales de contacto.
- Los números del dashboard son ficticios y están marcados como datos ilustrativos; cámbialos por datos autorizados o elimina las métricas.
- No se deben presentar testimonios, clientes, certificaciones ni métricas como reales si no han sido verificados.
- La demo es una representación de diseño, no una aplicación clínica funcional. La IA de detección, los protocolos, la seguridad de datos y la integración hospitalaria requieren desarrollo, evaluación y validación antes de cualquier uso real.
- El resultado de visión artificial no debe sustituir la revisión del personal clínico ni las políticas del establecimiento.
